# Changelog

## 0.10.0 — Public test release preparation

- Add backend setup and diagnostics to the sidebar and extension preferences.
- Pin NVIDIA MotionBricks v0.2.0 at `54fc563aeaaf819a753d72cc9fdc6713989cdd43`.
- Download the SOMA rig and selected ONNX assets with Git LFS SHA-256 verification.
- Support retrying setup, directory locking, process-tree cancellation and optional FP32.
- Recognize Linux and Windows virtual-environment Python paths. Linux is tested; Windows needs full validation.
- Add Chinese and English installation information, third-party notices, a feedback template and tagged prerelease builds.

## 0.9.0

- Pose naming, search and custom groups persisted in the blend file.
- Pose group rename, move and removal, with group inheritance for edited poses.

## 0.8.0

- Motion search, source/directory filters and optional selection playback.
- Timeline scrubbing and direct pose capture into the start/target sequence.

## 0.7.0

- Synchronized PMX preview with animation and IK restoration.

## 0.6.x
